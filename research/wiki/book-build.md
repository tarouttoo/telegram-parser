# Сборка BOOK.md

> Подсистема: `research/book/BOOK.md` — автосборка всех глав и приложений
> в один файл. Процедура верифицирована байт-в-байт 2026-11-05 при правках
> по ревью (commit `66fd9a7`). Отдельного скрипта сборки в репо нет —
> сборка делалась bash-конвейером.

## Формат

- **Шапка**: строки 1 … (первая `^---$` − 1): заголовок, строка «Собрано
  автоматически <дата>», оглавление с якорями.
- **Тело**: главы через разделитель, порядок:
  `00-prolog … 15-pnl`, `A1-glossary`, `A2-sources-map`, `A3-open-questions`.
- **Разделитель — байт-точно `\n---\n\n`**, НЕ «\n\n---\n\n»: файлы глав
  уже кончаются на `\n`, поэтому видимый вид «пустая строка / --- / пустая
  строка» складывается как контент+`\n` + `\n---\n\n`. Проверено
  байт-в-байт 2026-11-06 при пересборке второго прохода (до этого в этой
  заметке был неверный «\n\n---\n\n» — из-за него две попытки сборки не
  сходились по срезам).
- **A1 и A3**: при сборке их h2 `## Приложение` повышается до
  `# Приложение` (первое вхождение); у A2 в файле уже h1.
- **Переводы строк**: каждый файл заканчивается одним `\n`; после
  последнего файла (A3) лишний `\n` не добавлять.
- **Заголовки h1 глав менять нельзя** — оглавление BOOK.md привязано к
  ним якорями.

## Ловушка (проверено 2026-11-05)

При пересборке не читать шапку из целевого файла внутри
`{ … } > BOOK.md`: редирект группы **усекает файл до выполнения**
первой команды, и `head` получает пустоту — шапка молча теряется
(случилось и было исправлено в commit `66fd9a7`). Правильно: сначала
`N=$(grep -n '^---$' /tmp/BOOK.pre.md | head -1 | cut -d: -f1)`,
`head -n $((N-1)) /tmp/BOOK.pre.md > /tmp/hdr.md`, потом конвейер.

## Верификация сборки

Сравнение «части изменились — только нужные» по маркерам заголовков:
для каждой пары соседних `# Гл. N.` взять срез
`[index(mark_i), index(mark_{i+1}))` в старом и новом файле и сравнить
строки, предварительно отрезав хвостовой разделитель `\n---\n\n`.
Поймки 2026-11-06: (1) разбиение по `\n\n---\n\n` через `re.split`
ненадёжно — не использовать; (2) словарь срезов по маркеру
`# Приложение\.` схлопывает три приложения в один ключ — срезать
списком кортежей, не dict.
