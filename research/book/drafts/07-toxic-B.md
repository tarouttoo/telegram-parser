## Телеметрия: кто кого толкнул

### Сквозная телеметрия: граф «кто кого толкнул» (alko-trading#1278)

Сквозная телеметрия — запись 2–3 дней всех трейдов инструмента в граф (graph) на ~100 ГБ RAM: по графу видно, кто кому предшествовал и с какой латенси. alko называет вещь «сквозной телеметрией»; ChatGPT опознал в ней Bloomberg TCA «на стероидах» (alko-trading#1278).

| Параметр записи | Значение |
| --- | --- |
| Окно | 2–3 дня всех трейдов инструмента |
| Данные трейда | размер, метка времени до 0.5 ms |
| Флаг трейда | «пробивал стакан / нет»; вышедшие в wash исключаются |

Классификация по графу: всё, что объяснилось, — механика рынка; необъяснимое — ритейл (alko-trading#1278).

Активные трейды кормят мейкера, реактивные и есть toxic flow «в чистом виде» (alko-trading#1278).

### Главный детектив: источник токсика — сам автор (alko-trading#1618)

Полгода alko искал источник токсика, бившего его связку binance-via-bybit на XMR: телеметрия показывала волну «binance → bybit за 22 ms» при минимальной сети 32 ms. Разгадка: это был он сам (alko-trading#1618):

| Звено | Событие | Время |
| --- | --- | --- |
| alko | арбитражит whitebit→binance — двигает binance | 69 ms |
| другой игрок | видит трейд alko на whitebit — тейкает bybit | 80–95 ms |
| телеметрия | честно рисует «binance → bybit с пиком на 22 ms» | пик 22 ms |

«Я генерирую toxic flow для binance, а кто-то присосался ко мне» (alko-trading#1618).

Количественно (alko-trading#1619): 20% всех движений bybit порождает whitebit со средним ущербом 13.5 bps на доллар объёма; ещё 14% — kucoinfp, копирующий bybit.

### Влияние — распределение, а не число (alko-trading#1620)

Записанный в телеметрию «okx → binance за 12 ms» не подтвердился: удары летят волнами без выраженного пика, первый удар — не главный. «Рыночек сильно медленнее и сильно неэффективнее, чем я представлял» (alko-trading#1620).

### Весовая модель: прекомпилированная модель монеты (alko-trading#1283, alko-trading#1630)

Граф трейдов с итеративным перераспределением весов — 100–1000 проходов до устаканивания — даёт прекомпилированную модель монеты (alko-trading#1283, alko-trading#1630):

- ритейл — узлы без входящих рёбер;
- токсик локализуется;
- видно, какие биржи обязаны участвовать в true price.

К 12-й ступени эволюции понимания в списке того, что «влияет» (alko-trading#1630):

- перекосы сайзов;
- касательные трейды (с фильтром wash);
- асимметрия бирж: bitmex генерит только sell-токсик, lighter — только buy;
- неразличимость европейских кандидатов (kraken/whitebit/bitfinex);
- зависимость от собственного сайза: «чем больший сайз я собираюсь поставить — тем сильно сложнее его там оборонять».

### Дешёвые прокси (alko-trading#1627, alko-trading#1769)

| Прокси | Что даёт | Механика |
| --- | --- | --- |
| перекос сайзов на poloniex | предсказывает движение binance/okx/bybit за 60+ секунд | единственный ММ полониекса агрегирует SIZE с глубины нормальной биржи, и его верхушка показывает size imbalance всего рынка (alko-trading#1627) |
| binance index | готовая приблизительная карта токсика по монете | то, «на какие цены он смотрит» (alko-trading#1769) |

## Канарейки: второй канал правды

### Собственный fill быстрее public-потока

Пока биржа врёт в дискретных снапшотах, честный канал — собственные исполнения:

| Биржа | Факт |
| --- | --- |
| binance | свой fill в private stream прилетает на 2.5–6 ms раньше public bookTicker (alko-trading#942) |
| binance | trigger-ордер по невозможной цене: expire-событие раскрывает направление движения бесплатно (alko-trading#942) |
| kucoin | колокация отдаёт private fill на 50–150 ms раньше public (alko-trading#1339) |
| bitget | API флашит буфер раз в 20 ms — свои канарейки единственный способ узнать о движении в реальном времени (alko-trading#1221) |
| binance spot | метки времени bookticker не существует — «только канарейки, только хардкор» (alko-trading#1288) |

### Шахтёрская канарейка (alko-trading#1325)

Термин — из шахтёрской канарейки (canary): лимитка на $5–10, которая филлится в момент палки и предупреждает за 1–2 ms; «канарейка дохнет — снимаем ордера» (alko-trading#1325).

Инженерия латенси и private/public потоки — (→ гл. 9).

## Экономика: диагноз минуса

### Девять компонент PNL (alko-trading#1644)

Раскладка PNL каждой сделки на девять компонент — jitter, clamp, true price, offset, toxic hedge, toxic fill, hedger loss, hedger slippage, fees — превращает «почему минус» в читаемый диагноз (alko-trading#1644):

| Токсичный компонент | Читаемый диагноз |
| --- | --- |
| toxic hedge | «не увидел удар со стороны, ищем источник» |
| toxic fill | «видел новую цену, но не успел отмениться, шлифовать cancel» |

### Цена ошибки: минус 1000 USDT за дырку в 1 ms (alko-trading#1720)

Одна дырка в 1 ms при трёх cancel-соединениях (первое затупило, второе отдало 429, третье было занято warmup) — минус 1000 USDT (alko-trading#1720).

Анатомия API и латенси — (→ гл. 9, гл. 12).

### Режим торговли: тысячи сделок каждую минуту (alko-trading#1829)

Стратегия сходится с симулятором только на тысячах сделок каждую минуту (alko-trading#1829). Частота пробоев на ETHUSDT (alko-trading#1829):

| Пробой | Частота |
| --- | --- |
| 1 bps | 1000 раз в час |
| 3 bps | раз в час |

Поэтому стоять можно на 1–2 bps от верхушки, не глубже (alko-trading#1829).
