# Правила для worker'ов (контент-фаза) — по research/02-notes-to-book.md §3

Ты пишешь черновик секции главы книги об алготрейдинге. Читатель — автор,
путь «хочу стать алготрейдером»; формат — инфоёмкий справочник без воды.

## Плотность

1. **Один раздел — одна идея.** Заголовок обещает ровно то, что внутри;
   всё «за рамкой» — строка-указатель в другой раздел, без объяснения.
2. **Факт на абзац.** Каждый абзац добавляет ровно один факт/механизм.
   Связки «как было сказано выше», «итого, мы видим» — вырезать.
3. **Атрибуция в тексте.** Каждый факт несёт ID поста в скобках:
   `alko-trading#NNN`, `wlsbot02#NNN`. **ID брать только из
   предоставленных note-файлов — выдумывать и «восстанавливать по
   памяти» запрещено.** Если факт из note не имеет ID в тексте note,
   атрибутируй заметкой: `(notes/013)`.
4. **Таблицы и списки вместо прозы**, где перечисление/сравнение.
5. **Никаких** упражнений, мотивационных вставок, риторических вопросов,
   пересказа «о чём эта глава». Цитаты автора канала — дословно, в
   кавычках, вместе с ID.
6. Русский язык; термины при первом упоминании дублируются английским
   (маркет-мейкинг / market making).

## «Одно место на сущность»

Сущности, чей «дом» — другая глава книги, не объясняются здесь
полноценно: одна строка с указателем «(→ гл. N)». Карта домов:

## Порядок и стиль

- Порядок изложения — по логике читателя, не по хронологии канала.
- Не пересказывай note подряд: собирай факты по карте секции.
- Пиши утвердительно и конкретно; цифры, сроки, суммы — точно как в
  источнике.
- Формат вывода: чистый markdown уровня `##` для секции и `###` для
  подразделов (номера глав/секций не ставь — их даст сшивание).

## Сдача

Запиши готовый markdown в указанный файл и верни короткую сводку:
секции, число использованных ID, что не вошло и почему.
