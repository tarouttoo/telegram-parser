## Лид-лаг: слушать лидера

Лид-лаг (lead-lag) — сделка на бирже-последователе по сигналу движения
цены на бирже-лидере.

Прототип wlsbot02 (март 2025) — план из четырёх шагов: «1. ОЧЕНЬ
внимательно слушаю че происходит на БИНАНСЕ. 2. жду, когда кто-то выкупит
что-то, двигая цену на >0.2%. 3. ОЧЕНЬ быстро бегу на Байбит и пытаюсь
выкупить это же по цене с запасом. 4. в случае неудачи я ничего
не теряю» (wlsbot02#27).

Результат на момент поста: микро-капитал без каких-либо оптимизаций
скорости «уже ловит профиты на жирных парах» — ZRO 0.43% (wlsbot02#27).

Открытая проблема прототипа — «как считать справедливую цену для покупки»
(wlsbot02#27); справедливая цена / fair price — (→ гл. 7).

### Метод grisha: бот как зонд биржи

Освоение любой новой биржи по grisha начинается с лид-лаг-бота с предиктом
(predict): записать маркет-дату → исследовать API на максимум возможностей
— реальные rate limits, ошибки, тайминги матчинга в разных режимах →
поставить бота → получить срез своих возможностей на этой бирже
(grisha#134).

Бот эволюционировал в «зонд» — лид-лаг с предиктом + мейкер-тестер
в одном (grisha#145); устройство зонда и статистика прогонов — (→ гл. 12).

Лид-лаг-ветка wlsbot02 выросла в арку о «подводных субмаринах» — (→ гл. 9).

## Снайпинг листингов

Свой парсер листингов Upbit/Bybit (пост 29.10.2025): вход — пробиванием
прайс-лимитов (price limit), «почти каждый раз вхожу первым в обновившийся
прайс-лимит» (wlsbot02#80).

Разбор входов «через микроскоп» (06.11.2025) — три типа кейсов:

- где купил вовремя;
- где «лимитка на 2кк USDT тыкается на 300 мс»;
- где «быстрый вебсокет опаздывает на пол секунды» (wlsbot02#81).

Финал ветки (10.12.2025): «очень кайфовал от снайпера листингов, пока они
не затухли» (wlsbot02#91).
