# Приложение. Карта источников

Навигация по корпусу: три канала → рубрики канала alko → notes → главы.
Назначение — обратная трассировка: каждая глава перегенерируема из корпуса
(правила сборки — `research/02-notes-to-book.md`), каждая цитата в книге
несёт ID поста и резолвится через `knowledge/index/posts.jsonl`.
