# Приложение. Карта источников

Навигация по корпусу: три канала → рубрики канала alko → notes → главы.
Назначение — обратная трассировка: каждая глава собрана из корпуса,
каждая цитата в книге несёт ID поста вида «канал#номер» и разрешается
по этому корпусу.

## Явно вне книги

- `people-community` (158 постов) — тема «сцены»: стратегическое,
  рисковое и инфраструктурное отфильтровано в главы через notes №011,
  персоналии — вне книги.
- `hft-underground` — в нормализованный корпус не разобран (вынесен
  в отдельный экспорт вне корпуса); единственный известный будущий
  источник — задел на второе издание (→ «Открытые вопросы»).

Сопутствующие приложения: «Глоссарий» (A1) — термины из корпуса с
указателями на главы; «Открытые вопросы» (A3) — граница знания книги.
