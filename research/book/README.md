## Правила главы (кратко — полные версии по ссылкам выше)

- Один раздел — одна идея; факт на абзац; атрибуция ID в скобках
  (`alko-trading#788`, `grisha#66`); таблицы вместо прозы; без
  упражнений и воды; сущность объясняется полноценно в одном месте.
- Сырьё: notes по карте раздела + точечные посты; каждый факт
  прослеживается до источника.
- В конце главы — карта источников (какие notes/посты легли в раздел).

## Цикл «глава за сессию»

1. Главная сессия: выписать по карте темы таксономии, notes, посты.
2. Суб-агенты `worker` — черновики секций (каждому: список источников +
   правила плотности + требование атрибуции).
3. Главная сессия: сшивание, дедупликация, порядок.
4. Суб-агент `reviewer`: факт-на-абзац, атрибуция, «одно место на
   сущность».
5. Автор читает, правит, коммитит; обновить статус в этой таблице.
