## Рейт-лимиты из условий программы (вырезано из секции «Рейт-лимиты»)

- по условиям ММ-программы спота: публичные запросы 200/300/400 в секунду
  по IP, приватные 200/300/400 по счёту, постановка и отмена делят квоту
  400/600/800 в секунду — уровни T1/T2/T3 (grisha#138, grisha#139);
- по июльским условиям фьючерсов было 100/100 и 10 субаккаунтов с высокими
  лимитами; тейкер-заявки — 5 в секунду общие на все счета по картинке
  условий, менеджер назвала 30 (grisha#138) — переписка с менеджером биржи;
- из строки «ММ | фьючерсы» таблицы «Замер пачками» убрано «(их до 10)»
  (число субаккаунтов — из условий программы); из строки ММ-спот убран
  ярлык уровня «T1».

## Комиссии фьючерсов (вырезано из «Фьючерсы: четыре режима» и соседних абзацев)

- ММ-программа: группа BTC (BTC, BNB, BCH, PAXG) 2,5/0 по июлю → 3,5/0 по
  октябрю; остальные 8/1 → 10/1,5; вход: оборот >50 млн USDT/мес при доле
  мейкера ≥80 %, без уровней;
- парадокс режимов с точными цифрами: «по тейкеру ММ платит вдвое больше
  розницы через сайт» — 8 против 4; «ММ выигрывает у розницы только против
  API и только мейкером: 1 б.п. вместо 6, на группе BTC 0 вместо 1;
  против веб-канала выигрыша нет — у него тот же 1»;
- круг сделки (вход тейкером, выход мейкером): ММ, обычная пара — 9 по
  июлю, 11,5 по октябрю; группа BTC — 2,5 / 3,5; розница сайт после
  антифрода — 5 везде, на месяц;
- розница после письма антифрода: 4/1 на всех 44 фьючерсах, на месяц;
  API остался 8/6 — его антифрод не трогал.

## Комиссии и вход спота (вырезано из «Спот: два режима»)

- ММ-программа: тейкер 2,5 на всех уровнях; мейкер-доплата −0,25 / −0,5 /
  −0,75 б.п. на T1/T2/T3 — биржа доплачивает; T0 — 2,5/0;
- вход в ММ-программу спота: доля 0,2/0,5/1 % всего мейкер-объёма спота
  MEXC или свой объём от 50/120/240 млн $/мес (T1/T2/T3), квалификация
  помесячная.
