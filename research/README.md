# Research · Эффективная работа с большим корпусом текстов

Исследовательская фаза перед созданием **книги об алготрейдинге** —
**завершена**. Канал `alko-trading` дописан автором полностью, корпус
по нему финален: оглавление зафиксировано (`outline.md` v3), начата
контент-фаза (черновики глав — `research/book/`). Эта папка остаётся
методологической опорой книги.

## Контекст решений (зафиксирован до исследования)

- **Читатель книги — автор** (аспирация: стать алготрейдером). Хребет:
  механика рынка → **стратегии** (основа заработка) → **проблемы
  реализации** → риск.
- **Формат** — плотный справочник («механика рынка, только про
  алгоритмы»), без упражнений, на русском, термины с английским.
- **Сырьё** — корпус постов (`grisha`, `wlsbot02`, `alko-trading`) и
  выжимки `knowledge/notes/001–013`; notes остаются как есть.
- **Статус корпуса**: alko дописан автором полностью — рост корпуса
  прекращён; единственный известный будущий источник —
  `hft-underground` (экспорт без разбора, после первого издания).
- **Проверка приёмов** — на живом корпусе; приёмы проектируются под
  инкрементальные поступления (канал продолжает пополняться).
